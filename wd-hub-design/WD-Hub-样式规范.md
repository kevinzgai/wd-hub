# WD Hub（WorkBuddy Hub）界面样式规范

> 适用硬件：ESP32-C3 AI Passport，240×320 ST7789P3 竖屏，无触摸，UP / DOWN / OK 三键。
> 设计基线：官方 passport-os 像素风主题（travel 调色板）+ LVGL 9，无 GPU。
> 固件工程：`/Users/kevin/WebstormProjects/passport-workbuddy`。
> 本规范与同目录 `.design` 画布中的 10 张 240×320 画板一一对应。

---

## 0. 结论先行

**推荐方向 A「仪表像素」**。

核心理由：

1. **它像 Launcher 的第四张卡，而不是第四款产品。** 直接复用官方 travel 调色板、32px 页头、22px 页脚、1px 描边、4px 圆角和像素方块语言；不引入新 logo、新图形系统或新的字号。
2. **只靠两种字体也能建立层级。** 每屏只放一个 `montserrat_32` 大数字作为第一视觉锚点，其余全部 `buddy_font_16`；靠颜色、底板、3px 竖条和留白区分层级，不依赖 12/20/24px 字号。
3. **语义色不被品牌色污染。** 在线/正常/运行用鼠尾草绿 `#9DB89A`，高危/等待用珊瑚红 `#F09B87`，离线/次要信息用灰 `#B3B2A5`；琥珀 `#DDB36C` 只负责品牌、选中态、大数字和数据条。
4. **LVGL 成本最低。** 全部是实色矩形、1px 描边、3px 竖条和 4px 圆角；没有模糊、渐变、阴影、位图背景和大面积动画。
5. **一屏能排完。** 所有页面的信息都按 16px 中文的字符预算重新写过，超长内容用省略号，不引入滚动容器。

方向 B「赛博终端」和方向 C「极简深色」见第 1 节；它们作为对比稿保留在画布中，但不作为落地方向。

## 1. 三种视觉方向

| 方向 | 一句话定位 | 与 Launcher 的关系 | 主要问题 |
|---|---|---|---|
| **A 仪表像素（推荐）** | 官方像素主题的直接延伸：琥珀数字、奶油文字、硬边框、小圆角。 | 同一套页头/页脚/卡片语言，放在三个官方应用旁边仍然像「同一个固件里的工具」。 | 信息密度高时略硬；需要严格控制每屏只放一个大数字。 |
| **B 赛博终端** | 绿磷光、方括号标题、分段式进度条、全屏细框。 | 终端气质强，但页头/页脚语言与官方 Launcher 不同。 | 绿色与官方 `success` 语义冲突；没有卡片层级，远看像另一个产品。 |
| **C 极简深色** | 大留白、无卡片、细线分隔、单色文字 + 一条琥珀进度线。 | 颜色仍来自官方调色板，但结构语言接近「设置页」。 | 告警/审批的紧迫感弱；可用面积浪费，240×320 上不划算。 |

**选择 A 的边界条件：** 如果后续官方 Launcher 改成全新视觉系统，A 需要跟着换 token；但页头/页脚/卡片/按键条的**结构**仍然可以保留。

## 2. 品牌命名与 Launcher 落地

### 2.1 命名

- 产品名：**WD Hub**（两词，首字母大写；不写「控制台 / Console」）。
- 全称：**WorkBuddy Hub**（只出现在关于页或 README，不进入常规页头）。
- 设备 BLE 名：**WD-HUB-C3**。
- 模块/代码内部仍可保留 `wb_console` 等标识；**所有用户可见字符串**统一为 `WD Hub`。

### 2.2 Launcher 卡片

- 卡片名：**WD Hub**
- 副标题：**工作台**（16px，灰色；只有空间足够时显示）
- 位置：第 4 张卡，排在 游戏 / 俄罗斯方块 / 设置 之后。
- 卡片外观：沿用官方卡片形状、1px 描边、4px 圆角；用 3px 琥珀竖条或 22×18 琥珀索引块做识别，**不要**新画一个彩色大图标。
- 图标建议：16×16 的 2×2 像素块（琥珀 + 奶油两色），或直接用索引块里的 `4` / `W`；不引入新的图片资源。

### 2.3 页头标题

- 常规页面：只写页面名，不重复品牌。
  - `状态总览` / `会话列表` / `今日消耗` / `关于 / 链路` / `命令审批` / `提问`。
- 关于页卡片头：**`WD HUB · 链路`**，作为整屏唯一的品牌落点。
- 不要在每页写 `WD Hub · 状态总览`：240px 宽 + 16px 中文字体，会把右侧状态挤掉。

### 2.4 待机页品牌位

- 位置：屏幕上方居中，`y=40`，高 16px。
- 表现：`WD HUB` 用 `buddy_font_16`，字距 4px，颜色 `#B3B2A5`，左侧一个 4×4 琥珀方块。
- 不做大 logo、不做吉祥物、不做大面积高亮白；待机是低亮度场景，品牌只做「水印级」存在。

### 3.2 语义映射（必须按状态选色，不按「好看」选色）

| 语义 | 颜色 | Hex | 使用位置 |
|---|---|---|---|
| 在线 / 正常 / 运行 / 完成 | 鼠尾草绿 | `#9DB89A` | 页头「已连接」、配额「正常」、会话「运行」、待机「在线」 |
| 告警 / 额度偏低 / 需要关注 | 琥珀 | `#DDB36C` | 额度告警文字、告警徽标、需要用户注意的非破坏性状态 |
| 危险 / 等待审批 / 高风险 | 珊瑚红 | `#F09B87` | 审批页「高危」、会话「等待」、拒绝块、不可撤销提示 |
| 离线 / 空闲 / 次要信息 | 灰 | `#B3B2A5` | 离线、空闲、ID、辅助说明 |
| 品牌 / 选中 / 数据 | 琥珀 | `#DDB36C` | 大数字、选中行、选中卡边框、进度条、用量条 |

### 3.3 使用规则

- **一个页面只允许一个「品牌琥珀大面积」**：大数字或选中行。不要把琥珀同时用在标题、数字、三个进度条和页脚上。
- **状态色只做小面积**：4×4 点、16px 文字、26px 高的操作块；不要整屏铺绿或铺红。
- **不要用透明度做「变暗」**：直接换 `#B3B2A5` 或 `#303738`，避免 LVGL 大面积 alpha 混合。
- **16bpp 取色会有 ±1 LSB 偏差**：`lv_color_hex(0xDDB36C)` 在 RGB565 下不是逐位精确；以屏幕实拍为准，不要用取色器反推 CSS。

## 4. 字体层级与文案预算

### 4.1 只有两种字号

| 字体 | 字号 | 用途 | 禁止 |
|---|---|---|---|
| `buddy_font_16` | 16px | 中文、页头标题、标签、会话名、命令、选项、页脚、次级数字 | 不要用它强行加粗/斜体；不要用它做 32px 大数字 |
| `montserrat_32` | 32px | 每屏唯一的关键数字：额度 `820`、tokens `82.4K`、待机时钟 `23:41` | 不要用于中文；不要在一屏放两个 32px 数字 |

> 行高按 20px（或字体自带行高）排；**20px 是行高，不是第三档字号**。若 `buddy_font_16` 的实际行高不是 20px，以字体度量微调 y 坐标，不要新增字号。

### 4.2 层级建立方式

1. **面积**：32px 数字占 32px 高，16px 文字占 20px 高。
2. **颜色**：主文字 `#EEE7D6` > 次文字 `#B3B2A5` > 轨道 `#303738`。
3. **底板**：页头 `#303738` > 卡片 `#202526` > 屏幕 `#181B1C`。
4. **边**：1px `#59605D` 边框；选中时 3px 琥珀竖条。
5. **不要**靠第三种字号、粗体、斜体或阴影建立层级。

### 4.3 文案预算（216px 内容宽，按 16px 中文 ≈ 13.5 字/行）

| 区域 | 上限 | 超长处理 |
|---|---|---|
| 页头标题 | 8 个中文字（含 `/`） | `LV_LABEL_LONG_DOT` |
| 会话名 | 7 个中文字 / 12 个 ASCII | 省略号 |
| 会话副行 | 13 个中文字 | 省略号 |
| 命令原文 | 3 行，每行约 23 个 ASCII | 第 3 行省略，或让 host 端先截断 |
| 问题 | 2 行 × 13 个中文字 | 省略号；不要出现第 3 行 |
| 选项 | 1 行 11 个中文字 | 省略号 |
| 页脚提示 | 12 个中文字 / 24 个 ASCII | 缩短动词，不要换行 |
| 状态徽标 | 4 个中文字 | 用「运行/等待/空闲/离线」四词 |

## 5. 几何、间距与组件

### 5.1 全局几何

| 区域 | y | 高度 | 说明 |
|---|---|---|---|
| 页头 | 0 | 32px | 背景 `#303738`，底部 1px `#59605D` |
| 内容区 | 38 | 250px（38–288） | 左右各 4px 安全边；卡片宽 232px |
| 页脚 | 294 | 22px | 4px 外边距；高 22px；圆角 4px |

- 所有 x / y / w / h 用整数；不做 0.5px 描边。
- 基础节奏：**4 / 6 / 8 / 12 / 16 / 20 / 22 / 32**。卡片之间 6px；卡片内边距 8px；行高 20px。
- 卡片：`x=4, w=232`，1px 描边，4px 圆角；**不要**阴影、不要双层边框。
- 3px 竖条：作为独立矩形放在卡片左侧（`x=4, w=3, h=卡片高`），LVGL 不支持「只加左边框 3px」的样式。
- 选中卡：1px 琥珀描边 + 3px 琥珀竖条；不要发光、不要放大。
- 页脚圆角 4px；索引块、操作块、选项行、进度条全部 **0 圆角**。

### 5.2 页头组件

- 索引块：`22×18`，`x=6, y=7`；底色琥珀，文字 `#181B1C`，16px，居中。
- 标题：`x=34, y=6, w≈150, h=20`；16px `#EEE7D6`，左对齐。
- 右侧状态：右对齐，距右 6px；4px 点 + 5px 间距 + 16px 文字；颜色按语义。
- 页头不允许出现第二个按钮或图标；三键设备的操作全部在页脚提示。

### 5.3 页脚按键提示条

- 位置：`4, 294, 232, 22`；背景 `#202526`；1px `#59605D`；4px 圆角。
- 文字：16px `#B3B2A5`，居中；键名用琥珀（如 `OK`、`长↓`）。
- 文案模板：
  - `OK 打开 · ↑↓ 选择`
  - `OK 允许 · 长↓ 拒绝`
  - `OK 下项 · 长↓ 提交`
  - `OK 重连 · ↑↓ 翻页`
- **不要**在页脚放三个以上的动作；超过三个动作说明页面信息架构需要收敛。

### 5.4 卡片组件

- 背景 `#202526`；1px `#59605D`；4px 圆角。
- 内边距 8px；标题行 20px；分隔线 1px；行距 20px。
- 3px 竖条颜色：主卡/选中=琥珀；高危=珊瑚红；链路正常=鼠尾草绿。
- 卡片内不再嵌套卡片；需要分组时用 1px 分隔线，不要用第二层底板。

### 5.5 进度条与用量条

- 额度进度：`214×8`；轨道 `#303738` + 1px `#59605D`；填充琥珀；0 圆角。
- 模型用量：`80×6`；轨道同色；前 2 名填充琥珀，其余填充 `#B3B2A5`；0 圆角。
- 不画百分比刻度、不画发光端点、不做圆角胶囊。
- LVGL 用 `lv_bar`；关闭动画；只更新 value，不重建对象。

### 5.6 状态徽标

- 形态：**4×4 方块 + 5px 间距 + 16px 文字**，不用胶囊底色。
- 原因：16px 文字 + 胶囊内边距会超过 20px 行高，且 232px 宽度下会挤掉名称/数值。
- 颜色按 3.2 的语义表；文字颜色与点一致。
- 需要强调时，给整行加 1px 左边条或改变行的背景，不要给徽标加底色。

### 5.7 审批操作块

- 允许：`4, 232, 232, 26`；实底 `#9DB89A`；文字 `#181B1C`；0 圆角；文案 `OK · 允许执行`。
- 拒绝：`4, 262, 232, 26`；实底 `#F09B87`；文字 `#181B1C`；0 圆角；文案 `长按 ↓ · 拒绝`。
- 两块等宽等高，颜色即语义；不要给其中一个加阴影或描边来「抢焦点」。
- 物理键没有触摸焦点态；如果需要「按下反馈」，只做 1px 奶油色内描边，不做缩放/发光。

### 5.8 选项行

- `232×22`，0 圆角，1px `#59605D`；行内：16px 字母键 + 6px 间距 + 16px 文本 + 右侧 4×4 标记。
- 选中：整行琥珀底，文字 `#181B1C`，右侧标记变 `#181B1C`。
- 最多 6 行；行距 2px；总高 `6×22 + 5×2 = 142`，从 `y=138` 到 `y=280`。
- 选项超过 6 个时不让列表滚动，改为「更多」页或由 host 端合并选项。

## 7. LVGL 9 落地说明

### 7.1 颜色

```c
#define WD_BG          lv_color_hex(0x181B1C)
#define WD_CARD        lv_color_hex(0x202526)
#define WD_MUTED       lv_color_hex(0x303738)
#define WD_BORDER      lv_color_hex(0x59605D)
#define WD_TEXT        lv_color_hex(0xEEE7D6)
#define WD_TEXT_DIM    lv_color_hex(0xB3B2A5)
#define WD_PRIMARY     lv_color_hex(0xDDB36C)
#define WD_ON_PRIMARY  lv_color_hex(0x181B1C)
#define WD_SUCCESS     lv_color_hex(0x9DB89A)
#define WD_DANGER      lv_color_hex(0xF09B87)
```

- `lv_color_hex()` 在 16bpp 下会做 RGB565 量化；不要拿 CSS 的 hex 和屏幕取色器逐位比对。
- 需要统一改主题时，只换 `WD_PRIMARY` 与 `WD_SUCCESS` 两个值即可切到 classic 主题；其他中性色不变。具体 classic 值以 `main/ui/ui_palette.h` 的 classic 分支为准。

### 7.2 尺寸与位置

- 直接把第 6 节的 x/y/w/h 写进 `lv_obj_set_pos()` / `lv_obj_set_size()`。
- 卡片：

```c
lv_obj_t *card = lv_obj_create(parent);
lv_obj_set_pos(card, 4, 38);
lv_obj_set_size(card, 232, 92);
lv_obj_set_style_bg_color(card, WD_CARD, 0);
lv_obj_set_style_bg_opa(card, LV_OPA_COVER, 0);
lv_obj_set_style_border_color(card, WD_BORDER, 0);
lv_obj_set_style_border_width(card, 1, 0);
lv_obj_set_style_radius(card, 4, 0);
lv_obj_set_style_pad_all(card, 8, 0);
lv_obj_remove_flag(card, LV_OBJ_FLAG_SCROLLABLE);
```

- **3px 竖条不是一个 border-left**：LVGL 的 `border_width` 四边同宽。做法是单独创建一个 `3×H` 的矩形：

```c
lv_obj_t *rail = lv_obj_create(card);
lv_obj_set_pos(rail, 0, 0);
lv_obj_set_size(rail, 3, 92);
lv_obj_set_style_bg_color(rail, WD_PRIMARY, 0);
lv_obj_set_style_bg_opa(rail, LV_OPA_COVER, 0);
lv_obj_set_style_border_width(rail, 0, 0);
lv_obj_set_style_radius(rail, 0, 0);
lv_obj_remove_flag(rail, LV_OBJ_FLAG_SCROLLABLE);
```

### 7.3 字体选择

| 内容 | 字体 |
|---|---|
| 页头标题、索引数字、会话名、模型名、命令、选项、页脚、次级数值 | `&buddy_font_16` |
| 额度 820、tokens 82.4K、待机 23:41 | `&montserrat_32`（若工程内符号名不同，按实际 font 符号替换） |

```c
lv_obj_set_style_text_font(label, &buddy_font_16, 0);
lv_obj_set_style_text_font(big_num, &montserrat_32, 0);
```

- `montserrat_32` 只用于数字/ASCII，**不要**把中文丢给它。
- 不要为了「看起来小一点」去生成 12/20/24px 字体；现有字库只有 16 和 32。
- 需要次级数字（积分、消息数、服务 ID）时，用 `buddy_font_16` 的 ASCII 字形，不要开第三档字号。

### 7.4 文本截断

```c
lv_obj_set_width(label, 108);
lv_label_set_long_mode(label, LV_LABEL_LONG_DOT);
lv_label_set_text(label, "Claude Code");
```

- `LV_LABEL_LONG_DOT` 只在设置了固定宽度时生效；否则标签会按内容宽度撑开。
- 中文省略号在 LVGL 里可能显示为 `...`；如果要求中文「…」，在 host 侧预截断字符串，LVGL 只负责显示。
- 多行文本不要依赖自动换行：按视觉稿拆成独立 label，y 间距 20px；LVGL 的字体行高由字体文件决定，不能像 CSS 那样任意设 `line-height`。

### 7.5 进度条 / 用量条

```c
lv_obj_t *bar = lv_bar_create(card);
lv_obj_set_pos(bar, 15, 110);
lv_obj_set_size(bar, 214, 8);
lv_bar_set_range(bar, 0, 1000);
lv_bar_set_value(bar, 820, LV_ANIM_OFF);
lv_obj_set_style_bg_color(bar, WD_MUTED, LV_PART_MAIN);
lv_obj_set_style_bg_opa(bar, LV_OPA_COVER, LV_PART_MAIN);
lv_obj_set_style_border_color(bar, WD_BORDER, LV_PART_MAIN);
lv_obj_set_style_border_width(bar, 1, LV_PART_MAIN);
lv_obj_set_style_radius(bar, 0, LV_PART_MAIN);
lv_obj_set_style_bg_color(bar, WD_PRIMARY, LV_PART_INDICATOR);
lv_obj_set_style_radius(bar, 0, LV_PART_INDICATOR);
```

- `LV_ANIM_OFF` 是默认值；确保没有全局动画。
- 5 个模型条用 5 个 `lv_bar`，不要用一个容器画 5 段；这样每次只更新 value，成本低。

### 7.6 状态点与选中态

- 4×4 点：`lv_obj_create()` + `lv_obj_set_size(4,4)` + `bg_color` + `radius 0`；不要用图标字体或位图。
- 选中卡：1px `WD_PRIMARY` 边框 + 3px 竖条；不要加 `shadow`。
- 选中选项：整行 `bg_color=WD_PRIMARY`，文字 `WD_ON_PRIMARY`，右侧 4×4 标记换成 `WD_BG`。
- 按键没有触摸反馈：不要给按钮加 `LV_STATE_PRESSED` 的缩放/变色；如果需要反馈，只加 1px 内描边。

### 7.7 页面生命周期

- 每个页面一个 `lv_obj` 根容器，`wb_console_view_enter()` 创建，`exit()` 删除；不要缓存 `lv_screen_active()` 屏幕指针。
- 所有容器 `lv_obj_remove_flag(obj, LV_OBJ_FLAG_SCROLLABLE)`；屏幕本身也不可滚动。
- BLE 帧到来时只更新对应 label / bar 的文本和 value，不重建整屏。
- 时间更新只改时钟 label；不要整屏 `lv_obj_invalidate()`。

## 8. LVGL 9 + 无 GPU 的昂贵 / 不可行清单

| 视觉手段 | 可行性 | 原因 | 替代做法 |
|---|---|---|---|
| 大面积模糊 / 毛玻璃 | 不可行 | 软件逐像素卷积；240×320 全屏成本高，且 LVGL 9 无原生 blur | 用 `#202526` / `#303738` 两层实色底板 |
| 渐变（背景 / 按钮） | 不推荐 | `bg_grad` 逐像素插值，增加渲染时间和代码复杂度 | 实色 + 1px 描边 + 3px 竖条 |
| 阴影 / 发光 | 不推荐 | `shadow_width` 会扩大绘制区域，软件渲染成本高 | 1px `#59605D` 描边；选中用琥珀竖条 |
| 全屏位图 / 扫描线纹理 | 不推荐 | 需要 240×320 图片资源 + 额外 RAM/Flash；缩放/平铺更贵 | 用 1px 分隔线、4px 方块和留白制造像素感 |
| 大面积动画（滑动、呼吸、闪烁） | 不推荐 | 持续重绘；BLE 低功耗场景不应常亮动画 | 状态变化时瞬时换色/换文本；待机时钟每分钟更新 |
| 圆角胶囊 / 大圆角 | 不推荐 | 每个圆角都要抗锯齿；240 宽屏幕上收益低 | 4px 圆角卡片；按钮/选项/进度条 0 圆角 |
| 透明度叠层 | 不推荐 | alpha 混合增加每像素成本，颜色也不稳定 | 预计算实色：`#B3B2A5`、`#303738` |
| 滚动容器 | 禁止 | 用户明确要求一屏；LVGL 滚动在无触摸三键设备上体验差 | 严格文案预算 + `LV_LABEL_LONG_DOT`；超限改信息架构 |
| 变换（旋转 / 缩放） | 不推荐 | `transform` 走额外绘制路径 | 直接画目标尺寸的矩形/文字 |
| 图标字体 / SVG | 不推荐 | 增加字库/解码；与像素风也不一致 | 4×4 方块、1px 线、字母键 A–F |
| 多字体字号 | 禁止 | 字库只有 16 / 32；额外字号会显著增 Flash | 16 + 32 两档；用颜色/底板/边条分层 |

**性能预算建议：**

- 单页 LVGL 对象数控制在 60–90 个（本设计大约 70 个/页）。
- 单页不要超过 2 个 32px label。
- 避免每帧重绘全屏；BLE 更新只 invalidate 变化的 label/bar。
- 待机页是低亮度场景：时钟琥珀、文字灰、无大面积白；背光用官方 BSP 亮度接口和 Settings 熄屏策略，不在 view 里直接调背光。

## 9. 关键取舍

1. **为什么不用 32px 做页头标题？** 240px 宽下，32px 中文标题只能放 7 个字，且会和大数字抢层级；页头统一 16px，靠索引块和底板识别。
2. **为什么状态徽标不用胶囊底色？** 16px 字 + 胶囊内边距会超过 20px 行高，232px 宽度下会挤掉名称和积分；4px 点 + 文字最省空间。
3. **为什么运行态用绿色而不是琥珀？** 琥珀留给品牌、选中、数据条和告警；绿色专门表示「健康/在线/运行」，避免「运行」和「告警」同色。
4. **为什么允许块是实底、拒绝块也是实底？** 审批是二元决策，两个动作必须同等可读；颜色区分语义，不靠大小或阴影制造偏向。
5. **为什么待机页没有页头/页脚？** 待机是低亮度休息态，页头/页脚会制造「还在工作」的视觉噪音；品牌位和唤醒提示已经足够。
6. **为什么关于页卡头写 `WD HUB · 链路`？** 这是整屏唯一的品牌落点，既不占页头宽度，也不在每页重复品牌。
7. **为什么 cyber 方向被否掉？** 它的绿色会与官方 `success` 语义打架，且全屏细框/方括号标题会把 WD Hub 拉出 Launcher 的视觉家族。
