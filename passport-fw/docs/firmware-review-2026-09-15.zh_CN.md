# Passport OS 固件检阅与优化记录

日期：2026-09-15。审查基线：`manchunx7-bit/passport-os`，`main`，提交 `e5dd58223d62c2be5de6ffcb370b0fcb7b04b11d`。

## 当前结论

已完成一轮源码检阅、跨页面视觉统一和功能修复，并通过 ESP-IDF 5.5.3 完整编译、镜像合并与分区保护校验。修改已提交到 `feature/retro-firmware-20260915`，见[草稿 PR #1](https://github.com/manchunx7-bit/passport-os/pull/1)。**构建通过，真机验收尚未完成。** 主分支未合并。

项目具备清晰的应用分层、共享 BSP、独立游戏逻辑和现成的固件分区校验。主要短板是视觉实现分叉、部分“已修复”注释与实际行为不一致，以及工程检查入口失效。继续增加页面装饰之前，应先使现有功能和验证流程可靠。

范围包括启动流程、应用注册与切换、首页资料与天气、收音机及配网、两套语音功能、两个游戏、共享 UI、构建与验证脚本。以源代码和原有 CI 日志为依据；没有在硬件上运行，不能据此证明音频、无线网络、显示 DMA 或所有并发路径安全。

## 已落实的视觉修改

以首页原有的绿磷光终端为基准：近黑绿底、分层暗绿面板、磷光正文、较明亮的次级文字、琥珀选中标记、方角细框。没有新增字体文件或全屏位图缓冲。游戏角色和方块继续使用有辨识作用的颜色。

| 页面 | 原有问题 | 本轮改动 |
| --- | --- | --- |
| 开机 | 光标在完整标题上移动，未真正逐字揭示；宽度写死 | 根据真实标题布局计算遮罩与光标位置，随进度揭示文字 |
| 首页 | 与其他应用配色来源分离，次级绿字偏暗 | 接入共享调色板，提高次级文字亮度，保留人像、时钟与底部艺术图 |
| 应用抽屉 | 单独维护颜色；图标内部仍用浅纸色；底部重复阴影字 | 使用同一调色板、暗底图标、单一提示标签 |
| 系统设置 | 蓝天草地与磷光桌面割裂，选中行依赖亮黄整块 | 暗绿行卡、琥珀边框、统一提示；应用名称显示为“设置” |
| AI 语音各状态页 | 纸卡背景与全机分裂；标题被全局顶栏遮挡；时间挤占电池文字 | 深色面板与状态徽章；标题移到顶栏下；时钟移到独立位置；正文与背景颜色分开处理 |
| 小智 | 浅色消息面板、圆角状态栏与其它页面不一致 | 方角终端消息区、统一提示、移除独立阴影对象 |
| 收音机及全部设置/配网子页 | 蓝黑底与首页不同；选中态文字对比不足 | 共用绿色底色与面板，保留琥珀调谐刻度；选中框统一；中文 SSID 改用更完整的现有字库 |
| 两个游戏 | 蓝天草地与其他应用不同 | 统一背景、标题、结果面板和提示；保留游戏对象颜色 |
| 手机配置页和配网成功页 | 现代圆角、渐变与设备不一致 | 终端配色、方角、等宽字体、可见键盘焦点和减少动画设置 |

共享背景删除了云、星星、花草、萤火虫及持续动画；不再保留“最近一个背景页面”的对象指针。昼夜接口保留，但不再自动切换为蓝天或夜景。**待机电流与实际内存收益尚未测量。**

## 已修复的功能问题

| 优先级 | 问题与影响 | 修改 |
| --- | --- | --- |
| 高 | 保存资料的网页 POST 没带 token，正常保存也会被拒绝 | 补齐请求参数；使用真实网页脚本进行回归验证 |
| 高 | 头像 POST 漏做 token 校验；鉴权失败实际返回 400 | 补齐校验并正确返回 401；查询参数按键解析并检查完整数字格式 |
| 高 | 唤醒时只吞掉 PRESS，后续 CLICK/LONG 仍可能操作应用 | 吞掉整个唤醒手势，直到下一次新的 PRESS 才恢复输入 |
| 高 | 页面 stop/start 与 on_key 可并发访问应用资源；等锁后未复查目标 | 应用切换与按键分发共用递归生命周期锁；获得锁后复查目标；活动 ID 使用原子变量 |
| 中 | LVGL 锁未获取也标记“已熄屏”；休眠等待期间可能忽略新操作 | 仅成功执行休眠后更新状态，持锁后重新检查最近活动时间；唤醒显示操作也持锁 |
| 中 | 小智长文本先截断后追加，单段超长消息仍可能膨胀；按字节截断会切坏中文 | 将保留内容限制在 1200 字节内，在 UTF-8 字符边界截取尾部，同时限制直接设置与追加路径 |
| 中 | 资料字段被静默截短，可能切断中文；结构体字符串检查可能越界读取 | 超长字段拒绝保存；固定数组使用有界长度检查 |
| 中 | 编辑城市后仍带着上一城市的经纬度 | 城市发生编辑后清空坐标，要求重新定位 |
| 中 | Wi-Fi 高优先级任务可能在创建者发布句柄之前结束；任务创建失败留在连接页 | 发布句柄后通过通知启动任务；创建失败恢复可重试页面；状态变量改为原子类型 |
| 中 | 配网成功延时结束后可能把已离开的页面切回抽屉 | 在切换前重新检查页面是否仍活跃；这不等于完全解决所有配网重入竞态 |
| 低 | 俄罗斯方块下一块预览总是黄色 | 暴露下一块颜色编号，预览显示对应颜色 |
| 工程 | 原有 CI 因脚本没有执行权限而退出，尚未编译 | 恢复构建、验证和 actionlint 安装脚本执行位 |
| 工程 | 静态验证引用不存在的测试及旧文件路径 | 补上回归测试、修正路径、增加可单独运行的主机测试入口 |
| 工程 | 收音机与共享字体头重复声明时 C/C++ 链接属性冲突 | 收音机复用共享字体声明，消除完整编译中的冲突 |
| 工程 | 离线镜像合并收到 `--flash_size detect` 而失败 | 使用明确的 8MB Flash 配置；芯片和分区布局不变 |
| 工程 | 固件校验器仍引用旧项目二进制名称及旧分区地址 | 对齐实际 `passport-os.bin` 和 `partitions.csv`，补充布局一致性回归测试，保留 cardid 和末尾 recovery 区域保护 |

token 仍由设备首页发送给访问者，本轮修复的是接口一致性，**没有把它升级成账号认证或私密配对方案**。

## 仍需处理的问题

1. **头像存储恢复策略**：`home_profile.c` 在 SPIFFS 挂载失败后自动尝试格式化，无法区分空白新分区与已有数据损坏；正式替换头像前先删除旧文件，改名失败时可能丢失旧头像。建议增加明确的存储恢复入口及保留旧头像的更新策略，并进行断电故障测试。
2. **配网完整生命周期**：本轮修复句柄发布顺序，尚未为扫描、连接、退出、重新进入建立完整的会话代号。旧 worker 超时后重新进入的路径仍需专项重构和压力测试。
3. **天气数据与服务异常**：天气缓存是共享结构体，数值解析缺少充分范围验证，需继续检查跨任务读写、错误天气数据、超长坐标和请求截断路径。
4. **低内存与失败反馈**：部分 LVGL 分配与设置存储失败仍没有完整用户反馈。不能只用纯逻辑测试证明所有页面可在低内存条件下创建。
5. **工程资料完整性**：先从项目的实际来源恢复缺失文档、准确依赖锁文件及其授权说明。不要为了让检查变绿而凭空编造规则文件或许可证。
