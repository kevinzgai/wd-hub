AI 随身语音电脑语音输入

设备与电脑连接同一 Wi-Fi。下载电脑端完整包，安装虚拟声卡和微信输入法（也可用其他支持快捷键的语音输入法），再启动语音转发器。

电脑输入设备选 CABLE Output；转发器输出选 CABLE Input。输入法快捷键与转发器保持一致。设备上键按住说话、松开结束，下键发送回车。

AI 随身语音项目、下载与完整教程

设置页可以离线使用。打开 GitHub 教程前，先完成设置并将手机切回能上网的网络；以后可从设备“设置 → 手机设置”再次查看入口。

备用入口使用文件选择器。请选 JPEG 或 PNG 图片；若图片只在相册中，先保存到“文件”。如果两个入口都打不开，保持连接设备热点，在系统 Safari／Chrome 地址栏输入 http://192.168.4.1；也可用电脑连接热点后上传。

彩色随身名片最多 6 张

最多保存 6 张名片或二维码。首页按上键打开，上下键翻页，确定返回。推荐 3:4 比例，二维码周围请保留白边。

改用相册选择

如果相册只能单选，请使用上面的文件多选入口；可先把图片保存到手机“文件”。在系统浏览器地址栏输入 http://192.168.4.1 打开设置页，可避免部分内置浏览器的限制。

选图后会逐张缩放至 240 × 320 并压缩；每张最多 24 KB，6 张最多 144 KB。替换、移除和排序在“完成设置”时保存。

Muse 语音助手可选配置

需要自己的 Muse 账号、手机 App 和 Gadget SDK Token。保存后，在设备应用中打开 Muse，再用手机 Muse 的“设置 → 设备 → 开发者模式 → 添加设备”配对。配对时选择设备当前连接的 Wi-Fi。

SDK Token 可在 Muse 官方设备接入网站 gadgets.muse.ai 申请。建议在连接设备热点前准备好。

Muse 项目与完整配置教程 · 需要联网查看。Muse 不需要虚拟声卡或微信输入法。

正在读取设备中的 Muse 配置…

电脑与设备需在同一局域网，代理需要允许局域网连接。使用电脑代理时，电脑和代理软件要保持运行。清空 IP 后保存可切回直连；不会解除已有配对。

仅使用自己的 Token，勿发送给他人。更换 Token 后需要重新配对。通过设备热点配置，页面不回显已保存的密钥。

Token 和电脑代理设置保存在这台设备，重启后仍可使用。也可以点下方“保存并完成设置”一起保存。
